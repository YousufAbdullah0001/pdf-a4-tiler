&#x20;PDF → A4 Tiler



Split large PDF pages into A4 sheets at \*\*true 100% scale\*\* — no scaling, no rasterization.



> Perfect for tiling large artwork, schematics, blueprints, or posters for physical printing.



&#x20;Features



\- True 100% Scale: Artwork placed at exact source size — print at 100%.

\- Crop Marks: 4-corner ticks in the margin that never cross the design.

\- Alignment Crosshairs: Registration marks for precise multi-sheet assembly.

\- Reference Scale Bar: 10 mm or 20 mm bar on every page.

\- Tile Identification: Page number, source page, row, and column in the footer.

\- Batch Processing: Process an entire folder into an `A4\_Tiled/` subfolder in one click.

\- Overlap Control: Adjustable overlap from 0 to 24.9 mm.

\- Portrait / Landscape: Selectable A4 page orientation.

\- Non-Destructive: Original files are never modified.

\- Vector Preserved: No rasterization — text and vector graphics remain crisp.
